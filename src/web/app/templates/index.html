Privacy

Uploads may be temporarily written to disk before redaction while they are received. We redact recognized secret patterns before creating a separate temporary file for analysis. Temporary files are cleaned up during normal request processing; abrupt process termination can interrupt cleanup. Redaction may miss sensitive data. Review your log before uploading.

Supported formats

Plain-text logs with a severity label:

2026-10-10 09:15:22 ERROR Database connection failed

…plus JSON-lines, auto-detected and converted:

{"timestamp":"2026-10-10T09:15:22Z","level":"error","message":"..."}

Private by design

  • Uploads use temporary storage during processing.
  • Recognized secret patterns are redacted before analysis; other sensitive data may appear in reports.
  • Analysis reports are stored for 7 days and then expire. We keep no upload archive and don't use uploads for training. Operational request logs are recorded.
  • No account needed for analysis — optional accounts use a session cookie to stay signed in. File contents are not logged or retained after processing.

What you get

  • Severity counts (INFO / WARN / ERROR / CRITICAL)
  • Recurring issues ranked by severity and frequency
  • A health verdict and the #1 thing to investigate
  • Malformed-line report so you know what was skipped

Built by someone on-call

StackSift is built by a production support analyst who triages 120+ incidents a month. It's the first five minutes of an incident, automated.
